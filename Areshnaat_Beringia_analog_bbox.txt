Areshnaat Beringia-Analog Bounding Box
=====================================

Requested construction
- North/South bounds from Tuktoyaktuk and Okha
- East/West bounds from Nordvik and Mys Vasil'yeva

Math
----
Map size used: 3600 x 1800
Displayed map is the vertically flipped DEM orientation.
Longitude to x: x = ((lon + 180) / 360) * width
Earth-analog latitude to display y after the new flip: y = ((90 + lat) / 180) * height
Equivalent legacy DEM sampling latitude: sampling_lat = -earth_lat

Interpretation note
-------------------
This construction uses the named Earth places only as analog anchors. Because Tuktoyaktuk and Okha define only latitude while Nordvik and Mys Vasil'yeva define only longitude, the final box is a synthetic analog region, not a direct four-corner polygon through those towns.
