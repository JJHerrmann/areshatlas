# Goblinoid Naming Canon
# Lungbayin

A compact naming framework for goblinoid place names using:

- Tagalog-inspired lexical bases as the semantic and phonological core
- Quechua-style suffixes for place, people, and regional forms
- Greek and Latin-style prestige affixes for colonial, naval, dynastic, and sacred names

## Usage Pattern

Base pattern:

`[optional prestige prefix] + [Tagalog base] + [Quechua suffix or prestige ending]`

Examples:

- `Dagat` + `marka` -> `Dagatmarka`
- `Ilog` + `llaqta` -> `Ilogllaqta`
- `Aure` + `Layag` + `ion` -> `Aurelayagion`
- `Arch` + `Bantay` + `or` -> `Archbantayor`

## Design Logic

This naming system reflects a goblinoid maritime daughter branch within the Sultanate sphere.

Unlike Apusimi, which keeps Quechua-style stems and suffixes aligned in a more inland and imperial register, goblinoid forms use Tagalog-rooted lexical bodies while retaining Sultanate administrative and territorial endings. This structure becomes the hallmark of:

- Goblinoid naval powers
- Shelf colonies and port duchies
- Maritime trade leagues, flotilla towns, and storm-coast enclaves

The result is a naming ecology that feels clearly related to the Sultanate order, but faster, saltier, and more coastal in the mouth.

## Sound Notes

Compared to Apusimi forms, Lungbayin should prefer:

- open syllables and fluid spoken rhythm
- strong use of d, g, l, ng, b, t, y, and w-like glide textures
- less mountainous weight and more maritime movement
- compact names that feel quick in speech but still formal in writing
- a sense of tide, harbor, mast, ford, fogbank, rope, reef, and trade

## Table 2. Quechua-Style Suffixes

| Suffix | Meaning / Function | Usage |
|---|---|---|
| -yuq | possessed of, having | Feature-rich regions, epithets, titled places |
| -n | in, at, locative ending | Compact settlement names, districts |
| -ta | practical place ending | Smaller sites, minor localities |
| -pampa | plain, open land | Lowland coasts, flat shore belts |
| -marka | town, province, civic place | Cities, districts, provincial ports |
| -llaqta | settlement, major inhabited center | Great ports, core towns, administrative hubs |
| -suyu | region, quarter, realm | Maritime regions, duchies, shelf divisions |
| -qocha | lake, inland sea, sacred basin | Estuaries, lagoons, ritual waters |
| -mayu | river, riverine place | River mouths, canal belts, inland deltas |
| -urqu | mountain, ridge, highland | Cliff forts, shelf headlands, sea-ridges |
| -kancha | enclosure, fortified precinct | Harbors, dock compounds, naval courts |
| -wasi | hall, house, institution | Admiralty halls, trade courts, shrines |
| -punku | gate, pass, threshold | Straits, harbor mouths, shelf-gates |
| -kuna | plural or collective people form | Confederations, fleets, folk groups |

## Notes

- Let prestige forms stay rarer than everyday port speech.
- Regional clusters should recycle a few roots so shelf maps feel historically related.
