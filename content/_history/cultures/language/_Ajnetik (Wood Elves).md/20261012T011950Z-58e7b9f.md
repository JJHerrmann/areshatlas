# Ajnetik

The wood elf tongue. Only the writing system is recorded so far; the naming
framework has not been written.

## Writing

- **[canon]** Wood elves write the same elvish script as the elves, unchanged. See [[_Xibanal (Elvish)]] and [[One Root, Five Hands]].
- **[open]** Whether wood elf usage differs from [[_Ahvesil (Sea Elves)]] in any way beyond vocabulary.
