# Ahvesil

The sea elf tongue. Only the writing system is recorded so far; the naming
framework has not been written.

## Writing

- **[canon]** Sea elves write the same elvish script as the elves, unchanged. See [[_Xibanal (Elvish)]] and [[One Root, Five Hands]].
- **[open]** Whether sea elf usage differs from [[_Ajnetik (Wood Elves)]] in any way beyond vocabulary.
